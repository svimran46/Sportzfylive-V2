Uses structured football broadcast listings to identify broadcasters for today's matches across multiple regions, then maps broadcaster names to your local channel catalog.

After matches are synced, the worker attaches local channels only when their channel record explicitly maps to a Streamed source identifier. The Streamed API documents these as provider/source IDs, not TV-channel names.

Sync + auto-link also runs automatically every 10 minutes.

Authentication uses the Cloudflare Worker ADMIN_TOKEN secret.

Broadcast syncing uses structured football TV listings rather than Streamed provider/source IDs. Add the Cloudflare Worker secret GOALDIR_TOKEN and optionally set BROADCAST_COUNTRIES to a comma-separated ISO country-code list such as MY,GB,US,ES,DE,IN,ID,AU,CA,BR. Channel records can also include broadcastName, broadcastNames, broadcastAliases, and country-code fields for precise matching.
